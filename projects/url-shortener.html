URL Shortener — ShortLinks

A full-stack URL shortener application built with Next.js, Tailwind CSS, Express, and MongoDB Atlas. Shorten long URLs, manage links, and redirect visitors instantly.

Next.js MongoDB Express Tailwind CSS Postman
View Code

Workflows

1. Shorten a URL
The user submits a long URL through the Next.js frontend (Tailwind CSS). The request hits a Next.js API route that talks to the Express backend.
2. Generate short code
Express validates the URL, generates a unique short code, and stores the mapping (short code → long URL) in MongoDB Atlas.
3. Redirect
When someone visits the short link, Express resolves the code from MongoDB Atlas and issues an HTTP redirect to the original URL.
4. Testing
All backend endpoints are validated with Postman to confirm request/response cycles, CRUD behavior, and schema design.

Architectures

Frontend:
Next.js pages + Tailwind CSS for a responsive, clean layout that calls the API routes.
API layer:
Next.js API routes → Express server → business logic for validation, short-code generation, and redirection.
Data layer:
MongoDB Atlas (cloud NoSQL) stores URL mappings with indexes on the short code for fast lookups and CRUD operations.
