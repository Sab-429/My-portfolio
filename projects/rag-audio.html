LangChain based RAG Audio Transcription Model

End-to-end Audio Intelligence system that converts raw audio into searchable, explainable knowledge using a RAG (Retrieval-Augmented Generation) architecture.

Python-3.10 Google Gemini 2.5 Flash bge-m3 Ollama scikit-learn NumPy Joblib
View Code

Workflows

1. Audio ingestion
Raw audio files are uploaded and fed into a multilingual transcription pipeline built on Google Gemini.
2. Transcription & chunking
Gemini produces a transcript, which is split using semantic timestamped chunking so every answer stays traceable to its source segment.
3. Embedding generation
Chunks are converted into local embeddings using bge-m3 via Ollama for fully private, offline-capable inference.
4. Retrieval & generation
A cosine-similarity retrieval engine (scikit-learn) finds the most relevant chunks, which are passed to Gemini to generate an explainable, grounded answer.
5. Storage
A modular JSON → Vector Store pipeline (NumPy + Joblib) persists embeddings for fast reuse across sessions.

Architectures

Ingestion layer:
Raw audio → Google Gemini (multilingual STT) → plain-text transcript.
Chunking layer:
Transcript → semantic timestamped chunks → metadata (start/end time, speaker, confidence).
Embedding layer:
Chunks → bge-m3 (via Ollama) → dense vectors → persisted with NumPy + Joblib vector store.
RAG layer:
User query → bge-m3 embedding → cosine-similarity search (scikit-learn) → top-k chunks → Gemini 2.5 Flash → grounded answer with citations.
