Anonymous-message application

Anonymous-message from any person to the user via a URL using advanced dev tools. A secure, deployable anonymous messaging platform.

AWS Next.js MongoDB Cloudflare Docker Nginx
View Code Live Deploy

Workflows

1. Message creation
A visitor opens a shareable URL, types an anonymous message, and submits it. Next.js handles the frontend form and sends the payload to the backend API route.
2. Backend processing
The Next.js API route validates the input and forwards it to the Express layer, which writes the message document to MongoDB Atlas with a unique link identifier and timestamps.
3. Delivery & retrieval
The recipient opens the anonymous link. The server resolves the unique ID, fetches the message from MongoDB Atlas, and renders it. JWT-based authentication (Next-auth) protects admin routes.
4. Deployment pipeline
The app is containerized with Docker & Docker Compose and deployed on AWS EC2 (Ubuntu 24.04 t3.micro). Nginx acts as a reverse proxy (3000 → 80, 443), HTTPS is enabled via Let's Encrypt (Certbot), and Cloudflare handles DNS + proxy.

Architectures

Client → Edge:
Browser ↔ Cloudflare DNS + Proxy (DDoS protection, caching, SSL termination at the edge).
Edge → Origin:
Cloudflare forwards traffic to Nginx reverse proxy on AWS EC2, which terminates HTTPS and forwards to the Next.js app on port 3000.
Origin → Data:
Next.js/Express app communicates with MongoDB Atlas over an IP-restricted connection for secure read/write of messages.
