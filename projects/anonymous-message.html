anonymousms

Anonymous feedback platform: register, verify email, share /u/<username>, receive anonymous messages on a protected dashboard. One Next.js monolith in one Docker container.

FrameworkNext.js 16.1.1 (App Router), React 19, TypeScript
AuthNextAuth.js v4, Credentials, JWT sessions
DatabaseMongoDB Atlas + Mongoose
EmailResend + React Email templates
UITailwind v4, shadcn/ui, framer-motion, sonner
FormsReact Hook Form + Zod, Axios
DevOpsDocker, Compose, AWS EC2, Nginx, Cloudflare, Certbot

7 DevOps

Production request path

Docker multi-stage build

Compose runs one service web on host port 3000 with restart: unless-stopped and env_file: .env. Atlas allows only EC2_PUBLIC_IP/32.

Deploy and operate

# deploy / update
git pull
docker compose up -d --build

# inspect
docker compose ps
docker compose logs -f web

# nginx + ssl
sudo nginx -t && sudo systemctl reload nginx
sudo certbot renew --dry-run
